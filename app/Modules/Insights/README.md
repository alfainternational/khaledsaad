# Insights — إحصاءات الزوّار بقياس داخلي بالكامل

**العقد:** لا مزوّد خارجي ولا سكربت طرف ثالث. مصدر كل رقم هنا شيئان لا ثالث
لهما: طلب HTTP وصل إلى هذا الخادم، وبيكون من متصفح الزائر إلى مسارنا نحن.
لا يغادر شيء الخادم، ولا يحجب المقياسَ مانعُ إعلانات، ولا يخضع لعيّنة.

## طبقتا الالتقاط

| الطبقة | ما تعرفه | لماذا لا تكفي وحدها |
| --- | --- | --- |
| `TrackVisit` (وسيط عام) | كل طلب فعلًا: المسار، المصدر، الجهاز، الرمز، زمن الاستجابة، البوتات، و404 | لا تعرف إن كانت الصفحة **قُرئت** |
| `resources/js/insights.js` | الزمن النشط، عمق التمرير، التفاعلات، المقاس، المنطقة الزمنية | يحجبها مانع الإعلانات ويفقدها زائر بلا JS |

الوسيط **عام لا داخل مجموعة web**: طلب لا يطابق مسارًا (٤٠٤) لا يمرّ بوسائط
المجموعة إطلاقًا، والروابط المكسورة التي يصلها زوّار فعليون من أهم ما تكشفه
هذه اللوحة. وكل كتابته في `terminate` بعد إرسال الاستجابة.

كوكيّا `ks_visitor` و`ks_visit` **معفيان من التشفير** (`bootstrap/app.php`)،
وهو شرط عمل الالتقاط العام لأنه يسبق وسيط فكّ التشفير في السلسلة.

## التعريفات

```
الزمن النشط     مجموع نبضات المتصفح — يتوقّف عند إخفاء التبويب أو الخمول
الزيارة         نشاط متصل ينتهي بسكون insights.session_timeout_minutes
الارتداد        صفحة واحدة + بلا حدث + زمن نشط < insights.bounce_max_seconds
الزائر الفريد   كوكي طرف أول عمره سنة (لا IP ولا بصمة جهاز)
القناة          الوسم أولًا ثم المُحيل — والدليل الخام يُحفظ مع النتيجة
البلد           inferred دائمًا: منطقة زمنية أو لغة، ولا قاعدة GeoIP
```

## قواعد ملزمة

- **لا يُخزَّن IP خامًا.** بصمة `hash_hmac` بمفتاح التطبيق، للتعرّف الاحتياطي فقط.
- **البلد `inferred` ولا يُرقّى.** يُعرض موسومًا «فرضية» ومعه أساسه وتغطيته (§٤.١، §٤.٣).
- **الصفر لا يعني «أقل من ثانية»** بل «لا قياس» — فجوة القياس تُعلن ولا تُجمَّل.
- **البوتات تُعلَّم ولا تُحذف.** زحف GPTBot وClaudeBot وPerplexityBot هو المصدر
  الداخلي الوحيد لسؤال «هل أنا مرئي للنماذج أصلًا»، ويُستبعد من أرقام البشر
  عند القراءة لا عند الكتابة.
- **زيارات الإدارة تُسجَّل وتُستبعد** بـ`insights.count_staff` — الاستبعاد عند
  القراءة، فيمكن التراجع عنه بلا فقدان بيانات.
- **لا حساب مقياس خارج `InsightsReport`** (§١٤): المتحكّم يختار المدة ويمرّر.
- **معاملات الرابط الحساسة تُحجب** قبل التخزين — تسريب جدول تحليلات يجب
  ألّا يكون تسريب حسابات.

## الصيانة

```bash
php artisan insights:rollup --days=2   # تجميع يومي، قابل لإعادة التشغيل بلا مضاعفة
php artisan insights:prune             # حذف الخام بعد مدة الاحتفاظ، والتجميع يبقى
```

كلاهما مجدول في `routes/console.php`. `prune` يجمّع قبل أن يحذف — الترتيب
المعكوس يمحو أيامًا لم تُجمَّع بعد فتختفي من التاريخ نهائيًّا.

## واجهة تسجيل حدث من أي صفحة

```js
window.ksInsights.track('diagnosis_started', { category: 'conversion' });
```

ما اسمه في `insights.conversion_events` يُحتسب تحويلًا ويُنسب **لأول** حدث في
الزيارة لا لآخره — النسبة لآخر ضغطة زر تمحو القناة التي جلبت الزائر أصلًا.
