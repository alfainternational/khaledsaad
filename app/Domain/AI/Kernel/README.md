# Agent Kernel — نواة الوكيل المحلي

> فلسفة: **الذكاء في التنظيم، لا في النموذج.**
> نظام ذكاء اصطناعي يعمل في كل أجزاء الموقع وفي كل الأوقات، على استضافة مشتركة
> عادية، بلا أي عملية خلفية دائمة (daemon) وبلا أوزان نماذج ثقيلة.

## لماذا هذا "ثوري" ومناسب للاستضافة المشتركة؟

النماذج التقليدية تحتاج عملية مقيمة في الذاكرة (RAM/GPU) تظل تعمل. نحن نقلب المعادلة:

| البُعد | الطريقة التقليدية | نواة الوكيل هنا |
|---|---|---|
| التشغيل | عملية دائمة (daemon/worker) | يستيقظ داخل طلب PHP-FPM عادي ثم يموت |
| الموارد | RAM/GPU كبيرة لأوزان النموذج | لا أوزان محلياً — منطق PHP خالص |
| الذاكرة | قاعدة متجهات + فهرسة خلفية | `workspace_data` + حساب صلة لحظي (MemoryScanner) |
| التوليد اللغوي | نموذج مقيم | نتيجة محلية قوية أولاً؛ LLM آخر ميل اختياري عبر API |
| العمل في الخلفية | queue worker دائم | Laravel Scheduler عبر cron (الاستضافة المشتركة تدعمه) |

## المكوّنات (مستلهَمة من تنظيم `D:\xampp\htdocs\cloud`)

| الملف | النظير في cloud | الدور |
|---|---|---|
| `AgentContext` | context/ | كل ما يراه العقل في لحظة الطلب (immutable) |
| `Brain` | coordinator/ + query.ts | دورة تفكير واحدة: استرجاع → اختيار مهارة → تشغيل → كاش |
| `SkillRegistry` | skills/loadSkillsDir | سجلّ المهارات، حلّ كسول من الـ container |
| `Contracts/Skill` | tools/ + skills/ | عقد المهارة الواحدة |
| `SkillResult` | — | نتيجة موحّدة مع دليل المصدر (local/llm/hybrid) |
| `Memory/MemoryScanner` | memdir/findRelevantMemories | استرجاع ذاكرة ذات صلة بلا متجهات |
| `Skills/NextStepSkill` | bundled skill | برهان عملي: توصية محلية كاملة بلا LLM |

## كيف "يعمل في كل أجزاء الموقع"؟

أي Controller / View / Middleware يحقن `Brain` ويسأل:

```php
$result = app(Brain::class)->think(new AgentContext(
    intent: 'next_step',
    workspace: $workspace,
    project: $project,
    userId: $userId,
));
// $result->toArray() — جاهز للعرض، مع كاش تلقائي 30 دقيقة
```

العقل حاضر في كل مكان لأنه مجرد خدمة تُحلّ عند الطلب — لا شيء يعمل بينها.

## التدهور الآمن (Graceful Degradation)

كل مهارة تُنتج نتيجة محلية قوية أولاً. صقل LLM (عبر `AiGatewayInterface`) اختياري
داخل المهارة فقط. لو غاب أي مصدر خارجي، تبقى النتيجة المحلية كاملة. لا انقطاع.

## خارطة التوسعة

- مهارات لكل أداة من الـ 20 (تغلّف المحرك المنظّم الموجود).
- `LocalLlmGateway` (Ollama/vLLM) كآخر ميل عند توفّر خادم خاص لاحقاً — نفس العقد.
- `autoDream` عبر cron: تلخيص الذاكرة وتقويتها ليلاً (بلا worker دائم).
