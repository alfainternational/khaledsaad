# وثائق التدقيق الخارجي — منصة «خالد سعد»

> **اقرأ [`../../CLAUDE.md`](../../CLAUDE.md) أولًا.** هو دستور المستودع ومصدر
> الحقيقة المعماري. هذه الحزمة **مواصفة نيّة**، لا خريطة ملفات.

## ما هذه الحزمة وما ليست هي

كُتبت من **تدقيق خارجي للموقع الحيّ** لا من قراءة المستودع. لذلك:

- **أعطالها الموصوفة حقيقية** — تُحقّق منها في الكود وثبتت مواضعها.
- **بنيتها المقترحة ليست البنية القائمة** — التعارضات محسومة في
  [`adr/0002-absorbing-the-audit-pack.md`](adr/0002-absorbing-the-audit-pack.md)
  ومعها **جدول تعيين** بين أسمائها وأسماء الشجرة الفعلية.

من يبني على أسمائها حرفيًا يُنشئ النظام الموازي الذي يمنعه الدستور.
