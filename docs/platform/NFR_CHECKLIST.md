# قائمة الجودة غير الوظيفية (مرجع سريع)

مستمدة من [CLAUDE.md](../../CLAUDE.md) ووثيقة UI.

## الأداء

- أهداف Lighthouse / تحميل الصفحات كما في خطة المنتج
- أصول Vite مبنية للإنتاج (`npm run build`)
- توليد AI عبر طوابير وليس بشكل متزامن من الطلب الطويل

## الإتاحة (a11y)

- عناوين هرمية، تباين ألوان، تسميات النماذج، تنقل لوحة مفاتيح

## SEO (الصفحات العامة)

- عناوين وصفية، بنية دلالية، روابط نظيفة

## الأمان

- CSRF على `web` (استثناء webhook معرّف)
- سياسات Laravel لكل إجراء حساس
- واجهة API العامة: Sanctum + حد معدّل

## الواجهة

- RTL افتراضي، دعم الوضعين الفاتح/الداكن حسب دستور المشروع
- لا بيانات وهمية في الـ Views — البيانات من الـ Controller

## اختبارات

- تشغيل `php artisan test` قبل الإصدار؛ توسيع التغطية للمسارات الحرجة تدريجياً.
