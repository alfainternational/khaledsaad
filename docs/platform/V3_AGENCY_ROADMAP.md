# خارطة إطلاق وضع الوكالة (Agency) — GA في V3

مرجع: [CLAUDE.md](../../CLAUDE.md) القسم 19 و Roadmap V3.

## مبني منذ البنية (لا يُعاد اختراع المخطط)

- `workspace_type` يتضمن `agency`
- جدول `clients` وربط المشاريع بـ `client_id` حيث ينطبق
- أدوار تشمل `client` عند التفعيل
- `entitlement` بمفتاح `agency_mode` / وحدات الوكالة

## إطلاق واجهة المستخدم (تدريجي)

| الميزة | هدف الإصدار المقترح |
|--------|----------------------|
| واجهات multi-client كاملة داخل workspace وكالة | Beta ثم GA في V3 |
| بوابات للعملاء (portals) | V3 GA |
| موافقات كاملة بين الوكالة والعميل | V3 GA |
| White-label | V3 GA (مدفوع عادةً) |
| تقارير فوترة لكل عميل | V3 GA |

## اعتماديات تقنية قبل GA

- سياسات وصول صارمة لكل `client_id`
- تدقيق `audit_logs` لإجراءات العميل والوكالة
- اختبارات تكامل لوضع `agency` في المسارات الحرجة
