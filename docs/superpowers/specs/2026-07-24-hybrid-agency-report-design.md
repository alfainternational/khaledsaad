# تصميم التحليل الهجين والتقرير الموحّد للوكالة

## القرار المعتمد

يعتمد المنتج تجربتين مترابطتين:

1. تحليل هجين أثناء تعبئة الأدوات: قواعد وحسابات فورية، ثم استنتاج ذكاء اصطناعي قصير بعد إكمال كل خطوة.
2. تقرير مشروع موحّد: يجمع أحدث تقرير صالح لكل أداة مكتملة ويخرج نسخة ثابتة قابلة للتسليم إلى وكالة تسويق.

لا يبدأ تنفيذ التقرير الموحّد حتى تجتاز المنصة الحالية بوابة الاستقرار كاملة.

## بوابة الاستقرار

تُعد المنصة مستقرة فقط عند تحقق الشروط كلها:

- نجاح جميع اختبارات Laravel، بما فيها اختبارات التقارير والمراجعة اليدوية والأسئلة التكيفية.
- نجاح `pint --test`.
- نجاح بناء Vite.
- نجاح `flutter analyze` وجميع اختبارات Flutter.
- عدم كتابة أي اختبار أو مولّد مؤقت خارج `D:\xampp\htdocs\khaledsaad`.
- احتساب درجة المشروع العامة من أداة الجاهزية فقط.
- مقارنة تقريرين من الأداة نفسها فقط.
- تطابق تقرير Flutter مع الويب في المراجعة اليدوية والمقارنة والمراقبة والتقييم، وعدم عرض اسم نموذج غير مرسل.

## التحليل الهجين

### الطبقة الفورية

تعمل دون استدعاء ذكاء اصطناعي، وتعرض:

- اكتمال الإجابات.
- الأسئلة الشرطية المنطبقة.
- التعارضات والنواقص.
- حسابات القمع والميزانية.
- المقارنات السوقية المخزنة.
- جاهزية البيانات للدخول في تقرير الوكالة.

### طبقة الذكاء المصغرة

تعمل بعد حفظ خطوة مكتملة، لا عند كل ضغطة، وتعرض:

- ما تعنيه الإجابات الحالية.
- مخاطرة أو فرصة واحدة.
- توصية أولية واحدة.
- سؤال تعميق اختياري عند الحاجة.

كل ناتج فيها موسوم بأنه «مؤشر أولي»، ولا يغيّر إجابات المستخدم ولا الدرجة الحتمية.

### العرض

- الويب: مساحة جانبية ثابتة لا تتجاوز ثلاث بطاقات.
- Flutter: بطاقة سفلية قابلة للفتح.
- الفشل في التحليل المصغر لا يمنع حفظ الخطوة أو متابعة المعالج.

## التقرير الموحّد

يُنشأ بعد إكمال الحد الأدنى من الأدوات الأساسية، ويضم الأدوات الإضافية المكتملة تلقائيًا. التقرير لقطة ثابتة؛ لا تتغير صفحاته بعد إنشائه إلا بإنشاء إصدار جديد.

المحتوى:

- ملف المشروع والهدف والميزانية.
- درجة الجاهزية العامة من `marketing-score`.
- درجات ومحاور الأدوات المكتملة كل على حدة.
- الجمهور والتموضع والعرض والمنافسون والقنوات والمحتوى وSEO والقمع والحملات.
- الأدلة والافتراضات والبيانات الناقصة.
- أولويات الأثر مقابل الجهد.
- خطة 30/60/90 يومًا.
- مؤشرات الأداء وخطوط الأساس.
- نطاق الوكالة وما هو خارج النطاق وملكية الحسابات وإيقاع المراجعة.
- أسئلة مقارنة عروض الوكالات.
- منهجية التقرير وتاريخ اللقطة ومستوى اكتمال البيانات.

## الخصوصية

كل معلومة قابلة للتصنيف إلى:

- تظهر للوكالة.
- تظهر كملخص.
- داخلية لا تدخل النسخة الخارجية.

الإصدار الأول يشارك PDF فقط. رابط المشاركة الآمن مرحلة مستقلة لاحقة.

## عدم الفشل

- فشل مزود الذكاء لا يمنع التحليل الفوري ولا التقرير الحتمي.
- لا تدخل نتيجة أداة غير مكتملة أو فاشلة في التقرير الموحّد.
- لا يُحسب متوسط مباشر بين درجات أدوات تقيس أشياء مختلفة.
- لا يُعرض ادعاء بلا دليل كحقيقة.
