# دليل اللغة العربية لمنصة خالد سعد

## الصوت المعتمد

تستخدم المنصة عربية واضحة ومحايدة يفهمها القارئ في أي بلد عربي. تكون الجملة قريبة وسهلة، من دون مفردات مرتبطة بلهجة محلية، ومن دون فصحى متكلفة أو مصطلحات تسويقية غير مشروحة.

نخاطب المستخدم بصيغة المفرد المباشر والمحترم: «أنت»، «مشروعك»، «يمكنك». لا نخلط بين المفرد والجمع في الرحلة نفسها، ولا نخاطب العميل بصيغة الغائب.

## المصطلحات المقفولة

| المفهوم | الاسم المعتمد |
|---|---|
| المساحة الرئيسية بعد الدخول | لوحة التحكم |
| كيان نشاط المستخدم | المشروع |
| الاستبيان التشخيصي | الأداة |
| محاولة استخدام الأداة | التشغيل |
| نتيجة الأداة | التقرير |
| الملف الجامع للوكالة | التقرير الموحد للوكالة |
| وحدات الاستخدام | الرصيد |
| مستوى الاشتراك | الخطة |
| الرسائل داخل الحساب | الإشعارات |
| الأعمال المستخرجة من التقرير | المهام |
| القياسات المتتابعة | مؤشرات الأداء |
| التقرير الذي يكتبه المختص | المراجعة اليدوية |

## المفردات غير المعتمدة

يمنع فاحص اللغة المفردات التالية في النصوص المعروضة:

| غير معتمد | البديل المحايد |
|---|---|
| دي | هذه |
| دا | هذا |
| وين | أين / إلى أي مرحلة |
| شنو، إيش، وش | ما / ماذا |
| منو | من |
| سوّي، سوي | نفّذ / أنشئ / أضف، وفق السياق |
| كده | هكذا / بهذه الطريقة |
| دلوقتي | الآن |
| مش | ليس / لا |
| عشان | لكي / حتى / لأن، وفق المعنى |
| اللي | الذي / التي / الذين |
| خلّيه، خليه | فعّل / اجعله، وفق المعنى |
| ما في | لا يوجد |

لا يكون الاستبدال آليًا إذا غيّر المعنى. تُعاد صياغة الجملة كاملة عند الحاجة.

## الأزرار

- يبدأ اسم الزر بفعل واضح: «أنشئ مشروعًا»، «احفظ الخطوة»، «نزّل التقرير».
- لا تستخدم العبارات المبهمة مثل «موافق» إذا كان الفعل المقصود حذفًا أو دفعًا.
- يذكر زر الإجراء المالي ما سيحدث: «ادفع واشترك»، «اشترِ باقة الرصيد».
- تكون أزرار الإلغاء محايدة: «عودة» أو «إلغاء».

## الأخطاء والحالات الفارغة

- تشرح رسالة الخطأ ما حدث وما يستطيع المستخدم فعله بعد ذلك.
- لا تلوم المستخدم ولا تعرض تفاصيل تقنية أو أسماء استثناءات.
- تفرق بوضوح بين انقطاع الاتصال، وعدم الصلاحية، والبيانات الناقصة، وفشل الخدمة الخارجية.
- تبدأ الحالة الفارغة بوصف الوضع، ثم تعرض فعلًا واحدًا واضحًا.

مثال:

> لا توجد تقارير لهذا المشروع بعد. أكمل إحدى الأدوات لإنشاء التقرير الأول.

## الأرقام والتواريخ

- يذكر الرقم مع وحدته ومصدره أو يوسم بأنه تقدير.
- لا تستخدم نسبًا أو أهدافًا بلا خط أساس.
- تعرض العملة بالاسم أو الرمز المعتمد في الحساب.
- تعرض التواريخ بصيغة ثابتة مفهومة، مع المنطقة الزمنية عند تأثيرها في الموعد.

## علامات الترقيم

- تستخدم الفاصلة العربية «،» داخل الجملة.
- تستخدم النقطة عند اكتمال المعنى.
- لا تكرر علامات التعجب.
- تستخدم الشرطة الطويلة باعتدال لشرح قصير، ولا تحل محل بنية الجملة.

## التقارير والذكاء الاصطناعي

- لا يعرض الادعاء غير المدعوم بوصفه حقيقة.
- تشرح المصطلحات في الجملة نفسها.
- تميز النتائج بين الحقيقة والحساب والمعيار الإرشادي والفرضية.
- لا تتحدث للمستخدم عن النموذج أو البرومبت أو مراحل النظام الداخلية.
- تنتهي التوصية بخطوة عملية قابلة للتنفيذ، لا بعبارة عامة.
